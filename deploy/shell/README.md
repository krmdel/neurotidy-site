Deployment shell for neurotidy.co. The build pulls dist/ from https://github.com/krmdel/neurotidy-site (main). Source of truth lives there. vercel.json carries the short typeable redirects (/tt, /ig, /cards, /deck) with and without the trailing slash, because trailingSlash normalization runs first. middleware.js logs AI crawler visits (BOTHIT lines) because static requests produce no logs; its user-agent list is vendored from ai-robots-txt/ai.robots.txt and kept in lib/distribution/seo/ai-bots.json in the business-os repo. Since 2026-10-05 the shell is versioned here (deploy/shell/) and deployed with `node src/deploy-shell.mjs` (Vercel API, VERCEL_TOKEN). It also 308s /index.html and /<dir>/index.html to the clean URL, extensionless /articles/<slug> to /articles/<slug>.html, and /quiz to /quiz.html, and skips our own audit's tagged GPTBot fetches in the bot log.
